# 🌤 Weather Forecast CLI App

Консольное Python-приложение для получения прогноза погоды на 3 дня с использованием OpenWeatherMap API.

## 📌 Описание

Пользователь вводит город, после чего программа выводит прогноз погоды на ближайшие 3 дня с разбивкой по времени суток.

## ⚙️ Возможности

- Поиск погоды по названию города
- Прогноз на 3 дня (включая текущий)
- Разбивка по времени суток:
  - Ночь (00:00–06:00)
  - Утро (06:00–12:00)
  - День (12:00–18:00)
  - Вечер (18:00–24:00)
- Расчёт средней температуры
- Непрерывный режим ввода городов
- Обработка ошибок (пустой ввод, неверный город, отсутствие интернета)

## 🧠 Технологии

- Python 3
- requests
- python-dotenv
- OpenWeatherMap API
